FINCONTROL - DOCUMENTO MESTRE DO PROJETO

Este documento descreve o planejamento completo do sistema FinControl,
um software web de controle financeiro pessoal desenvolvido para
portfólio profissional. O objetivo é simular o processo utilizado em
empresas: planejamento, arquitetura, implementação, testes e deploy.
