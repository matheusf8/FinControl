# FinControl

Sistema web de controle financeiro pessoal — projeto de portfólio.

**Stack:** React (Vite) + FastAPI + PostgreSQL, rodando 100% local via Docker.

> 🚧 Em construção. Veja o [plano de execução](./PLANO_EXECUCAO.md) completo.

## Como rodar (em breve)

```bash
docker compose up
```

## Estrutura

- `backend/` — API em FastAPI
- `frontend/` — interface em React
- `docs/` — documentação do projeto
- `backups/` — backups locais do banco (não versionado)
